
# 🕌 Islamy App

## 📖 Description

**Islamy App** is a must-have app for all Muslims. It provides easy access to the Holy Quran and Hadith, with a clean and user-friendly interface. The app supports both dark and light modes and offers multi-language support.

---

## 🌟 Features

- 📖 Quran Tab (List of Surahs)  
- 📄 Quran Details (Surah view)  
- 🗣️ Hadith Tab  
- ⚙️ Settings Tab  
- 🌗 Dark Mode / Light Mode  
- 🚀 Splash Screen  

---

## 🛠️ Tech Stack

- 💙 Flutter  
- 📦 Provider (State Management)  
- 🌐 Localization (Multi-language support)  
- 🌓 Dark & Light Themes
